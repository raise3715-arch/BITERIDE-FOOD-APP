Push App Update

"Push Update" replaces the app's code (app_config/html) for every restaurant partner automatically the next time they open or refresh it. "View Current Code" loads the currently-live pushed code into the box below so you can inspect or edit it before re-pushing. "Delete Pushed Update" removes app_config/html entirely (partners then keep using whatever copy of the app they already have loaded/cached, until you push again) — existing restaurant data (menu, orders, gpay, etc. under restaurants/*) is stored separately and is never touched by any of these actions.
